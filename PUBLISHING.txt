RRR.TRADING DAILY REPORT PUBLISHING

Homepage macro report integration:
- The homepage loads the saved daily macro report from /api/reports/macro/today.
- The browser requests the public API without cache, so the saved report appears on refresh.
- The site does not need to be rebuilt each day.

Daily publishing job:
1. Generate the normal daily macro report.
2. Publish the saved macro report through the existing backend workflow.
3. The homepage reads the saved report from the public API; no static frontend fragment is required.

Recommended later:
- Dated pages under reports/YYYY-MM-DD.html are static examples, not historical market reports.
